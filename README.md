# Champion Round – Junior Category

AG Spelling Bee Contest – Junior Category champion round (100 words, Science Y6) with part of speech, definition and recorded British English pronunciation.

## Use it offline
Keep this folder together and double-click `index.html`. Every recording is stored in the `audio` folder, so no internet is needed (the optional "Microsoft Sonia (online)" voice needs internet and Microsoft Edge).

## Put it on GitHub Pages (free, public)
1. Sign in at github.com and create a new **public** repository, for example `champion-junior-spelling-bee`.
2. Choose **Add file → Upload files**, drag in everything inside this folder (`index.html`, `README.md`, `.nojekyll` and the `audio` folder), then **Commit changes**. The whole folder is about 2.4 MB, so one upload is enough.
3. **Settings → Pages**: *Deploy from a branch*, branch **main**, folder **/ (root)**, **Save**.
4. After a minute or two the page is live at `https://YOUR-USERNAME.github.io/champion-junior-spelling-bee/`.

This page finds its recordings whether they sit inside the `audio` folder or at the top level of the repository.

## Sources
Definitions: Oxford Learner's Dictionaries and Merriam-Webster.
Recordings: open-source neural text-to-speech (Kokoro, British English voice "Emma"; some words use Piper "Jenny/Cori" where clearer), each checked by two automatic speech recognisers.
